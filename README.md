# MINESWEEPER COLLECTION

通常のマインスイーパーとは少し違ったルールで遊べる、変則マインスイーパーのコレクションです。

現在、2種類のマインスイーパーを公開しています。

どちらもブラウザ上で動作し、PC・スマートフォンからプレイできます。

## 🎮 収録ゲーム

### 24 MINESWEEPER

通常のマインスイーパーでは周囲8マスの爆弾数を表示しますが、このゲームでは **周囲5×5の最大24マス** の爆弾数を表示します。

広い範囲の情報を組み合わせて、爆弾の位置を推理するマインスイーパーです。

### POLYGON MINESWEEPER

正方形ではなく、**五角形・六角形のマス**を使用したマインスイーパーです。

- 五角形：辺または頂点で接するマスを数える
- 六角形：辺を共有するマスを数える

盤面の形状によって変化する隣接関係を利用して、爆弾の位置を推理します。

## 🕹️ 操作方法

### PC

| 操作 | 内容 |
|---|---|
| 左クリック | 選択中のモードで操作 |
| 右クリック | 旗の設置・解除 |
| Shift + 右クリック | ？の設置・解除 |
| R | リスタート |
| Esc | 難易度選択に戻る |

### スマートフォン

画面上の操作モードを切り替えてマスをタップします。

- **開く：** マスを開く
- **旗を立てる：** 爆弾があると思うマスに旗を設置
- **？ 仮置き：** 爆弾があるか分からないマスに目印を設置

旗と？は切り替え可能で、？を付けたマスはそのまま開くことができます。

## ⚙️ 主な機能

- 初級・中級・上級の3段階の難易度
- 最初のクリックの安全保証
- 旗・？によるマーキング
- 盤面の拡大・縮小
- プレイ時間の計測
- 効果音
- PC・スマートフォン対応

## 🌐 プレイ方法

GitHub Pagesで公開しているゲーム選択画面から、遊びたいゲームを選択してください。

ダウンロードやインストールは不要です。
